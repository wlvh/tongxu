## 本轮实际运行

在已交付的 v2.1 单文件基线上执行 v2.2 构建扩展，使用 Node 22.16.0 的 DOM/计时替身测试生成的完整脚本：新增 **39 项断言通过**；此前 v2.1 的 **36 项断言在同一新生成文件重放通过**。旧断言本轮使用已生成文件作为输入，而不是再次调用完整仓库构建链。旧构建转换以原 blob 字节保留，本轮没有从一个联网新克隆重跑整个两段构建；容器不能解析 GitHub 域名，仓库读写通过连接器完成。

复现入口（在正常克隆环境）：

```bash
python3 prototypes/build_product_ui.py
node verification/html_probes/current_v21.js
node verification/html_probes/current_v22.js
```

新增断言覆盖：秘书主页/只协调权限、未知文本不执行、新任务无写入、当前版本双方及接收反馈、独立接收路由、迟到反馈拒绝、精确 A1 前置、作者证据不等于接收、事件去重和新依赖变化触发、X2 不扩大 X1、秘书离线双方继续、只读拒绝与暂停后恢复。

这 75 项是离线行为断言，不是 75 项生产测试，不证明大模型听从提示或原生工具权限已经隔离。T01—T44 的产品验收依旧未执行。

## 浏览器检查

系统 Chromium 与 Playwright，内存 set_content 渲染。实际点击：新任务登记→A/B/接收角色反馈→秘书离线→PR201/202/203 按精确前置依次接收、确认与模拟合入→所有 PR 已合但 X 未完成→reject 不通过→单独 accept。无 pageerror。1440×1040 桌面和 390×844 手机的秘书与共同交付页未见页面水平溢出，明暗主题已检查。

浏览器测试最初使用旧动作名 verdict 导致等待超时；改为实际 receive-verdict 并等待接收回执后，同一路径通过。没有将这次测试脚本错误当产品缺陷。

未实测 file:// 原生打开、真实 localStorage 落盘、任意自然语言理解、跨工具 socket、运行中 Agent、真实 GitHub 合并和真实身份隔离。单文件 UI 没有网络依赖，下载后仍是离线演练。
