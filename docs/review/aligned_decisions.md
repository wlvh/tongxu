## 四、实测过的外部事实

- `git merge-tree --write-tree`（Git 2.43）：无冲突返回树 OID 退出 0；冲突返回树加冲突清单退出 1；工作区与 index 不动；对象库写入树；结果树可 `read-tree` 进隔离 worktree 运行测试。
- GitHub 合并接口只有 head 必须匹配的 `sha` 条件，无 base 条件；merge queue 文档页无可用性说明。
- Codex App Server 文档：`thread/start`、`thread/resume`、`thread/fork`、`turn/start`、`turn/steer`（需 `expectedTurnId` 匹配活跃轮次，无活跃轮次失败；不匹配时的行为文档未写明）、`turn/interrupt`；批准为服务端向客户端的请求。
- Claude Code 文档：跨会话消息用 `ListAgents`／`SendMessage`；运行中会话在工具调用之间读消息，空闲会话由消息开启新轮次；结果分 Delivered、Held、Refused；每个会话绑定本机 inbox socket（`CLAUDE_CODE_MESSAGING_SOCKET`），脚本可投递；`-p` 工作进程可收；Channels 为研究预览并带插件白名单。
- Claude Agent SDK 文档原文：未经批准，第三方开发者不得为其产品提供 claude.ai 登录或额度，包括基于 Agent SDK 构建的 agent；从其他语言驱动的方式是把 CLI 作为子进程用 `-p` 加 JSON 输出。
