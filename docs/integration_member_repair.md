## 当前入口与证据边界

`npm run member-repair -- run --plan /绝对路径/member-entry.json` 是单个操作入口。`prepare` 只固定输入；`reconcile-ended` 只在原执行已经结束并且原修复器核清现场时接续。入口固定原组合退回、成员项目请求、CLI 配置与原 operation；角色报告不能产生命令、权限或修改路径。成员使用自己的写入授权和资源，原父接收报告保持原身份，不制造成员自己的接收结论。

入口保存完整原件和生成的内部修复计划；原始选择文件随后被移走仍可读取本次完成结果。已完成执行在授权被撤销后仍可零新输入回读；未知或未结束执行不能用新 entry 标识绕过原计划。

新成员退回证据会令该成员旧接收结论失去当前适用性，并加入相关集成与交付成果的输入证据。旧报告、原 Owner 决定和准确候选均不改写；新证据不自动撤销用户授权，也不恢复已经停止的投入。队列格式显式升级到 19，保留原功能版本，首次升级要求队列空闲。

当前 MR01–MR03 有实际 Git／受管文件修改／Docker 测试／独立角色协议的隔离夹具验证；这些模型是明确的测试脚本。MR04 修复后重新组合、无修改反证后的新鲜接收，以及 MR05 真实 Agent 完整链仍在开发，不属于当前完成声明。原 MI05 部分 Git 执行接续仍单列。
