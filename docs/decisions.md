# 决定索引｜不代替原始采用

复用目标项目已有 decisions.md；此文件是 tongxu 的索引入口。没有可核验采用来源，不把模型整理的建议标为已采用。Milestone 描述、Issue 关闭和共用账号不能充当本人签字。

当前没有由本次修订新增并核实为“本人已采用”的判例。下列是字段模板，不是一次新授权：

```text
编号：TX-DEC-<顺序号>
状态：提出／已采用／已替代／已撤销
规则：……
适用条件：项目、成果、动作、后果、环境、资源与期限
不适用／例外：……
原始来源与采用者：固定记录，不是秘书摘要
替代／撤销：原编号＋新记录；不删除旧决定
本次复用：相同条件、差异、当前委托依据与实际处置引用
```

查到类似记录不等于适用。先核范围、后果和撤销；不适用但仍在技术委托内可由技术角色决定，只有真正越界才升级。历史一次性费用许可不扩为通用预算。修改本索引不能自行改变原决定。
