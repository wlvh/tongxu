## 目标

按已采用项目流程自动接续独立审核→必要核实→综合→授权修复→新候选再审。秘书只跟进与向用户汇报，不参加技术投票、不充当接收者。

## 范围

固定提示与候选 H/B/target/S/共同安排、真实 Run。采用 coding-workflow@1772cd2c 时，新独立 Codex 正式审核；新 Codex 核事实、独立 Claude Code 核影响；Codex 综合，分歧最多三轮证据交换。提示文件按 `prompts/README.md` 装配，不以原型缩写代替正式提示。

X 完成后固定顶层最终结果给 Y，不用中间 PASS、子代理或无效格式触发副作用。授权修复在核实会话实际移交写权后进行，未知不接管；本轮已明确授权不重复请示。错误 finding 用反证重审同 H，不制造空提交。

只计真实发布修复批次；超三次生成网页 GPT 简化反思待办。Owner 决定只暂停受影响范围，恢复不要求重选。新 head/范围/安排/相关 base 或新反例重核适用性，旧证据可复用不复制 PASS。

独立审核与接收两种结果分开，不为每 PR 新加固定签字层。技术接收以当前实际组合和授权为准，秘书不能覆盖。

## 验收

T13/T19/T22—T27，加 T33/T34/T44 相关部分。真实 PR 与可控响应分别记录；自动链无人工报告搬运、重复填 ID；缺上游正式提示或作者上下文污染不伪通过。无新计费、无通用流程编辑器、无运行中消息产品。
