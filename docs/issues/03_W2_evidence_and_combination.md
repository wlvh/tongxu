## 目标

调用项目已有检查，在隔离现场验证固定 B＋H 或最小必要组合，不改作者分支；为精确 PR 前置与共同用户场景提供可重跑证据。

## 范围

登记入口/参数数组/读写边界，固定代码、工具、输入和环境。用已验证 Git 能力计算 T，冲突交责任人；不把 read-tree 内容当实际 HEAD，不自动 rebase/cherry-pick/push。测试不带发布凭据。

同属 X 不默认所有 PR 绑定。支持 A1 兼容独立→B1 消费者→A2 入口的每步检查；只依赖明确能力或 PR，不等整个 Issue。确不可拆分时验证最小集成候选，保留完整差异，不用两次快速合并当原子。

复用已有原件/组合工具，不重造准备器。分类保留状态、内容、范围、身份和来源差异；缺材料/漏样本/空样本/工具失败不算无变化，成功→失败可为正确拒绝。工具自测也覆盖丢来源、工作进程失败与输入修改。

原审核与当前候选/计划适用性分别处理；相同 patch、无冲突、文件不重叠或现有 CI 成功都不独自证明组合正确。昂贵测试可有界复用/抽样并声明限制。

## 验收

T08—T12、T14/T16/T17 的相关部分，加 T39/T40 的组合候选。每步实际目标仍正常；未完成无关功能不被带入；作者现场与权限不变。无新的真实付费请求、无通用依赖分析器。
