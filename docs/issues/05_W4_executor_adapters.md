## 状态与目标

**规划级，G1 后细化。** 两种真实执行器的准确启动、指定接续、最终结果、原生批准与失败处理；按已验证操作开放能力。规范 §16/§17.2/§19 W4。

## 前置与接口调查

另固定本次 CLI／引擎版本、认证、预算和独立探针任务；不反向阻塞 W0/W1。Codex 非交互/App Server、Claude 非交互结构化输出与原生消息入口为候选，按实际安装帮助、固定源码及官方文档验证。不把历史文档转述当本机已经支持；不默认购买 API 或沿用订阅额度。

## Scope

- 分别验证两轮输入、真实 session/turn/workspace、指定会话接续、运行事件及顶层最终结果；中间日志／子代理回复不成为最终判断。
- 批准由实际客户端接住或明确可恢复停等；不得自动全同意。调查到授权修复的会话连续性必须实测。
- 能力为 **已验证版本操作与本次身份、连接、状态支持的交集**。握手不等于全能；已有能力证据可复用，不机械每会话重跑。无原生观察依据也不默认 observe。
- 错误 turn/缺活跃轮次不把 steer 失败降级为新轮次；没有准确 ID 不以最近会话代替。暂停请求、确认停写、后台命令和主进程退出分别处理。
- 探针只在独立测试会话；已有长期现场先关联观察，不迁移／重启／夺取控制。不可观察内部子代理就诚实标原生管理。

## 交付与验收

两种真实引擎的能力矩阵、事件和失败证据；T17/T19/T22/T26/T27。至少区分创建成功但不支持 pause、版本不符、握手未确认、无活跃轮次、原生等待。测试适配器不能替代真实接口证据；能力缺失只阻止相关后继。

## Non-goals

不先建统一抽象强迫原生适配，不恢复未知任务的替身，不接入新的计费路径，不改生产账号。
