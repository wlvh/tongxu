## 目标

交付真正可操作的产品界面：工作秘书首页＋原项目总览／任务会话PR／通信交付三工作区。不是方案阅读器，不能以离线演练代替真实接入。

## 范围

秘书对话显示真实来源、已登记/送达/接续/完成/未知；旁边是跟进、待决、成果。用户可直接操作同一后台，不必须经过秘书。秘书不显示代码/测试/技术验收/合并权；模型被诱导时后台仍拒绝。

新增任务接入页：相关负责人、未提交工作提示、当前版反馈、共享写责任、可独立继续部分。共同交付卡：本批 X 的目标与非目标、技术牵头、参与任务、实际 PR 前置、顺序/集成安排、启用与用户场景，X2 不偷偷加入。

原 PR 右侧抽屉保留当前候选、证据、真实目标、授权、迟到/未知恢复。秘书、任务、接收使用同一状态和原始记录；不新建前端布尔权威。每个按钮对应实际角色权限，不能将模拟注入动作带入生产。

保留 v2.1 原型36项所覆盖行为和 T01—T32：委托多维绑定、实际树不符待核恢复、base 适用性、分操作能力、单写、旧决定实施可重验、无效验收不变完成。新增 T33—T44 用户路径。

外部网页 GPT 技术解读/简化反思/验收计划合意仍按采用流程，秘书只准备入口与呈现；固定版本，历史不冒充当前，HTML 无控制权。安装升级停止接新写任务并保留恢复，失败退只读，不清空重派；秘书停止和浏览器关闭不自动取消已授权任务。

## 验收

T19—T21、T28—T44 及受影响回归。未参与实现者从秘书和三视图回答什么可用/缺什么/谁等谁/哪版验证/进入哪里/需本人决定什么。真实新任务与在途冲突协调、条件式合入、秘书离线、X1/X2、反馈过期和最终验收必须走通。验证明暗、键盘、桌面/手机、原始证据可读与无误导状态。

不以一个全绿截图结案，不新增计费面板/多仓库/通用流程编辑器；真实维护吞掉收益时缩小能力，准确命名阶段版本。
