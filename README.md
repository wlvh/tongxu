## 记录与公开边界

`docs/issues/`是受控发布源，原GitHub Issue为实施入口；一个执笔者发布并读回，不两端独立生效。历史材料在archive及review中，不作并行现行规则。T01—T52是未执行的产品验收清单，原型测试不是应用通过。

本次材料整理是用户委托代理完成，不等于本人逐项签署全部技术选择；身份、决定类型与依据须分开。公开文件与提交不新增凭据、私人路径、私人会话链接或原件。未重写历史。
