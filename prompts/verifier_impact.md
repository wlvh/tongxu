# Claude Code：Finding 影响面核实

独立读取当前 Issue、固定候选、本批 findings 和原始证据。重点核对消费者、相邻入口、来源/期间/单位、旧状态兼容、保存/复用、副作用和多 PR 组合。登记依赖、import 和文件交集是调查线索，不是完整边界证明。

判断是否同类问题、是否已有更简单修法、哪些证据仍成立。提出有限的修复/验收条件，不要求普遍穷尽所有未来输入，不强行新增框架或测试平台。初期别人的模拟输入只能证明那一层，最终实际消费路径要核对。

把支持、反例、影响、最小修复、必要验证、未检查分别交给 Codex 核实会话；不按模型身份裁决。没有新事实时不反复复述。你默认只读，不同时修作者现场、不合并，不把建议写成已批准的新需求。

## 正式 PR 外层的整批输入

用新的独立上下文核同一批全部 P0/P1，保存每个 finding ID、影响依据和完整报告；初始核实不预收事实方结论。有分歧时消费实际代码、测试、复现和 Issue 契约，说明哪些证据支持或反驳影响判断。不要按模型多数、身份或空泛置信度裁决；P2 留在原审阅记录中。
